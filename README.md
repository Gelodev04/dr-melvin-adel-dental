# Dr. Melvin H. Adel Dental Clinic

Clinic website + online booking (San Pascual, Batangas).

| | |
|---|---|
| Public site | http://localhost:3001 |
| Book | http://localhost:3001/book |
| Admin | http://localhost:3001/admin/login |
| Admin login | `admin@drmelvinadel.ph` / `demo1234` |

## Quick start

```bash
yarn install
yarn db:setup
yarn dev -- -p 3001
```

Sibling clinics live under `../` — see [`../README.md`](../README.md).
